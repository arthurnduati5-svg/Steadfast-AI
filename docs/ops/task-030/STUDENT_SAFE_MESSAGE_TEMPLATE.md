# Student-Safe Communication Templates

## When Expansion Is Not Available

> We are testing a controlled learning support feature with selected school accounts. If you do not see access, continue using your normal Steadfast learning space and ask your teacher if you need help.

## When Expansion Is Available

> Expanded learning support is available for your account. You can access these features when starting a new session. If you have questions, please ask your teacher.

## When Expansion Is Temporarily Paused

> Some learning support features are temporarily paused. Continue using your normal Steadfast learning space. Your teacher will let you know when features are available again.

## When Rollback Has Occurred

> The expanded learning support has been rolled back. Continue using your normal Steadfast learning space. If you have questions, please ask your teacher.

## Privacy Note

These messages do not:
- Expose other students' data
- Expose operations console internals
- Expose health or monitoring data
- Expose oversight items
- Expose teacher notes
- Reveal answer keys or assessment content
